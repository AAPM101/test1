# Skills

One definition per skill, same name in every tool. `registry.yaml` lists them (regenerated by `build/skills.py`).

- Create: `python3 build/skills.py new <name> --tool claude`
- Change: edit `<name>/SKILL.md`, then `python3 build/skills.py bump <name> --tool chatgpt --note "what changed"`
- Each skill folder has `CHANGELOG.md`: `date | tool | change | version`.

How each tool consumes them:
- Claude Code / Claude: the `<name>/SKILL.md` folder format works directly (symlink or copy into `~/.claude/skills`).
- ChatGPT / Grok: paste the SKILL.md text into a Project / custom instructions, or let the agent read the repo
  through a connector. When a skill's version changes, `python3 build/index.py` shows it in INDEX.md so you know what to refresh.
